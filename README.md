# 🎮 Colección de Juegos Web (HTML5, CSS3, JavaScript)

Colección de proyectos de juegos interactivos desarrollados en el navegador. Demuestra el uso de manipulación del DOM, físicas 2D/3D con **Three.js** y **Cannon.js**, y renderizado en **Canvas**.
